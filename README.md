# 🏠 Dormitory Management System

A full-stack web application for dormitory administration and automated utility billing.  
Built end-to-end as a **sole developer** during internship at Precise Corporation (PCC).

## 📋 Overview
ระบบจัดการหอพักครบวงจร ตั้งแต่การจัดการห้อง ผู้เช่า ไปจนถึงการคิดค่าน้ำค่าไฟอัตโนมัติ  
โดยเชื่อมต่อกับมิเตอร์จริงผ่าน Modbus Protocol บน Raspberry Pi

## ✨ Features
- 🏘️ Room management & tenant tracking
- ⚡ Real-time electricity & water meter readings via Modbus
- 🧾 Automated utility billing from live meter data
- 📄 PDF billing report generation
